STEP 9 — CHALLENGES FACED AND TECHNIQUES USED

9.1 Challenge: Understanding the Dataset
Technique: Exploratory Data Analysis (EDA)
Reason: To understand the dataset structure, data types, distributions, patterns and target variable.

9.2 Challenge: Handling Categorical Variables
Technique: One-Hot Encoding
Reason: To convert categorical values into numerical representations that machine-learning algorithms can process.

9.3 Challenge: Different Feature Scales
Technique: Feature Scaling
Reason: To put numerical features on comparable scales, which is particularly important for KNN, SVM and Logistic Regression.

9.4 Challenge: Avoiding Data Leakage
Technique: Scikit-learn Pipeline
Reason: To combine preprocessing and model training and ensure preprocessing is fitted appropriately without leaking test-set information.

9.5 Challenge: Choosing the Best Algorithm
Technique: Multiple Model Comparison
Models evaluated:
- Logistic Regression
- KNN
- Decision Tree
- Random Forest
- SVM
Reason: To identify a suitable model instead of assuming one algorithm would always perform best.

9.6 Challenge: Improving Model Performance
Technique: Hyperparameter Tuning using GridSearchCV
Models tuned:
- Logistic Regression
- KNN
- SVM
- Random Forest
Reason: To search for better hyperparameter configurations.

9.7 Challenge: Small Dataset
Technique: Stratified K-Fold Cross-Validation
Reason: To obtain a more reliable estimate of model performance across multiple splits rather than relying only on one train/test split.

9.8 Challenge: Evaluating Heart Disease Classification
Technique: Multiple Evaluation Metrics
Metrics used:
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- Confusion Matrix
Reason: Accuracy alone does not show all types of classification errors. Recall is especially important for identifying positive cases.

9.11 Challenge: Selecting the Final Model
Technique: Multi-Metric Model Comparison
Reason: To select the final model using accuracy, precision, recall, F1-score, ROC-AUC, cross-validation performance and interpretability rather than one metric alone.

9.12 Challenge: Avoiding Overclaiming Medical Results
Technique: Responsible Model Interpretation
Reason: The dataset is relatively small, so the model should be treated as a decision-support prototype rather than a standalone clinical diagnostic system. Larger independent datasets would be required for real-world deployment.
